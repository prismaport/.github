# Security

## Reporting a vulnerability

Please report a vulnerability privately through the affected repository's **Security** tab
("Report a vulnerability"). Do not open a public issue, discussion or pull request for it. If you
are not sure which repository it belongs to, pick the closest one: the report reaches the same
people.

Include what you found, how to reproduce it, and what an attacker could do with it.

There is no bug bounty at this time.
